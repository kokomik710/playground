## What the Rain Kept

A story-driven, low-poly third-person adventure in a single HTML file: [`what-the-rain-kept/index.html`](what-the-rain-kept/index.html).

Open the file in a desktop browser (an internet connection is needed once, to load Three.js from the CDN). No build step.

Currently included: the main menu, settings, pause menu, and the first location — Chapter One, *The Last Stop*.

Controls: `W A S D` walk · mouse look (click the game to capture the cursor) · `Shift` hurry · `E` look closer / continue dialogue · `Esc` pause.
